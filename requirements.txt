# ── Why these three are written twice ────────────────────────────────────────
# numpy, scipy and Pillow ship COMPILED wheels, one per Python version. The
# pinned versions below were built before Python 3.13 existed, so on a newer
# Python pip finds no wheel, downloads the source, and tries to compile it -
# which needs Visual Studio and fails like this:
#
#     ..\meson.build:1:0: ERROR: Unknown compiler(s): [['icl'], ['cl'], ...]
#     error: metadata-generation-failed
#
# That is what a fresh Python 3.14 install did: the whole install stopped at
# numpy, so NOTHING got installed, and the uploader then died on the first
# missing import (dotenv) every fifteen seconds.
#
# The markers below let pip pick per interpreter: the tested pins on the
# Pythons they were tested on, and the newest wheels on anything newer. One
# file, no choosing, and nothing has to be compiled either way.
numpy>=1.24,<2.0 ; python_version < "3.13"
numpy>=2.1 ; python_version >= "3.13"
scipy==1.11.4 ; python_version < "3.13"
scipy>=1.14 ; python_version >= "3.13"
